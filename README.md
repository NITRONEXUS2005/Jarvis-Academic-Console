# 🤖 Jarvis: ECE Academic Workspace Matrix

Jarvis is an automated local AI desktop assistant and syllabus optimization engine designed specifically for Electronics and Communication Engineering (ECE) students. Operating entirely on local resources via Streamlit and Ollama, Jarvis tracks study progress, generates custom summaries, extracts targeted exam questions, and automates contextual resource lookups.

---

## 🚀 Core Subsystem Features

* **Syllabus Progress Tracker:** Automatically manages tracking arrays across intensive technical subjects (Network Theory, Object-Oriented Programming, Semiconductor Devices).
* **Contextual Resource Router:** Bridges theoretical syllabus gaps by instantly mapping local study guides, verified external academic sites, and curated video reference matrices.
* **Local LLM Explanation Architecture:** Leverages quantized local language frameworks to generate granular academic overviews, dynamic mock quiz modules, and quick revision roadmaps.
* **Strategic Terminal Monitor:** A streamlined Streamlit terminal control board offering an administrative dual-column design separating real-time execution controls from live subsystem logs.
